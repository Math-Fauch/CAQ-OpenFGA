# OpenFGA technical talk — Slidev POC

A small, runnable presentation about **OpenFGA** using **Slidev**.

## Run it

```bash
pnpm install
pnpm run dev
```

Slidev opens the deck in your browser. Use the arrow keys to navigate and reveal content.

## Useful commands

```bash
pnpm run build   # production build in dist/
pnpm run export  # PDF export (uses Playwright Chromium)
```

## What is included

- `slides.md` — eight-slide OpenFGA story with speaker notes
- `style.css` — custom dark visual system
